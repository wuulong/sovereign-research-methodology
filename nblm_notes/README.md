### 📖 維度二：學術論證、公式外推與現地真值對合 (Claims & Ground-Truth Alignments)
*本組 Prompt 聚焦於探討如何透過肉身實踐的物理誤差（現地真值），對 LLM 的語意幻覺進行「謬誤剪枝」，並分析關鍵公式跨界外推的合理性。*

> **Prompt 2.1：從軟體工程 COI 到學術自審頻率 Fs 的公式螺旋外推**
> 「請詳細解讀論文手稿中如何借鑑 Aiersilan (2026) 關於軟體工程中量化認知卸載指數（COI）的公式：
> $$COI = 1.0 - \tanh(\alpha \cdot F_v)$$
> 它是如何被螺旋外推並重構為本論文的『Socratic 自審頻率 ($F_s$)』指標的？這項公式的外推，在量化思維主權邊界與防範研究生無腦拷貝上，具備什麼樣的科學與哲學正當性？」

> **Prompt 2.2：現地真值對合對抗語意閉環（RAGAS vs. 物理誤差）**
> 「文獻中的 RAGAS（Es 等人, 2023）評估框架本質上是『以 AI 評估 AI』的語意閉環，存在潜在的共謀幻覺。本方法論是如何利用 `empirical_evidences` 中的『現地真值對合（In-situ Ground-Truth Alignment）』與物理偏離度（friction_percentage）來打破這個閉環的？請結合水文流量模擬（Saint-Venant 方程式）的 Manning's n 阻力修正實例，說明物理約束如何強制校準 LLM 語意幻想。」

> **Prompt 2.3：學術重力場公式 Ga 的排序與優先級過濾機制**
> 「請解析學術重力場評估公式：
> $$G_a = (\text{被引用數} \times 0.40) + (\text{載體分值 Tier} \times 0.40) + (\text{年份懲罰衰減} \times 0.20)$$
> 它是如何引導 Navigator 在 Ingestion Pipeline 的步驟二中進行精讀優先級排序的？這項評估機制如何物理確保大腦的地基只靠泊高價值的頂級期刊（Top-Tier Venues）文獻，進而有效過濾掉公海文獻的語意泡沫？」

### 🎓 維度三：指導教授的 SQL 照妖鏡與師徒誠信防線 (Audit & Lab Pedagogy)
*本組 Prompt 旨在探討導師如何退後到物理盲檢，重建破裂的學術信任，以及如何制約學生的投機自審。*

> **Prompt 3.1：哈教授的 30 秒 SQL 照妖鏡實體運作**
> 「本方法論提出『從語意交鋒退後到物理盲檢』的新型教育評估範式。請詳細說明『哈教授的 30 秒 SQL 照妖鏡』在實際指導場景中是如何運作的？導師如何僅僅透過 4 大 SQL 指令，就能在不閱讀文字的情況下，穿透性地審查學生大腦中 Ingestion 血統、現地實測偏離度與紅軍 Verdict Lock 答辯日誌的真實度？」

> **Prompt 3.2：自審得分的防投機加權模型評析**
> 「在 MCI（手稿成熟與可信度指數）指標中，紅軍自審得分被設定為：
> $$\text{紅軍得分} = (\text{自審文獻覆蓋率} \times 0.6) + (\text{自審 PASS 率} \times 0.4)$$
> 為什麼覆蓋率的權重被剛性設定高達 60%？這項演算法是如何在物理上制約學生『僅自審 1 篇無關緊要的文獻並宣告 100% 通過』的投機取巧行為的？」

> **Prompt 3.3：Verdict Lock 合併阻斷鎖與答辯螺旋**
> 「請剖析 `academic-advisor-auditor` 的合併阻斷鎖（Verdict Lock）物理機制。當紅軍自審發現手稿主張存在漏洞並寫入 `'VULNERABLE'` 時，系統是如何拉下電閘、阻斷手稿編譯與發表的？研究生又必須經歷怎樣的『 Socratic 答辯螺旋』始能將狀態更新為 `'PASS'` 並重啟發表？」

> **Prompt 4.1：純文字 JSON 貢獻包（DTO）對抗 Git 二進位衝突**

> **Prompt 4.2：跳躍式知識遺傳與 Verdict PASS 軌跡繼承**
> 「什麼是『跳躍式知識遺傳』？在這套去中心化聯邦共有大腦中，當新進的學弟妹透過 DTO 一鍵 rebuild 大腦時，他們是如何在瞬間無損繼承歷代學長姐在資料庫中沉澱下來的 Verdict PASS 答辯戰役軌跡、Skills 封裝與 Ingestion 知識網絡的？」

> **Prompt 4.3：Eternal Skeleton (永恆基底骨架) 臨界失效重構分析**
